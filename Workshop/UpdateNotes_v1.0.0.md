# v1.0.0 发布说明（工坊公告 · 首次发布）

## 精细道路分类 v1.0.0 —— 首个公开版本

把原版只有 4 类（小 / 中 / 大 / 高速）的道路面板，细分成 **10 个实用分类**，并提供一个可以手动调整分类的管理器。

### 10 个分类
乡村公路 · 社区小路 · 小型道路 · 中型道路 · 主干道 · 大型道路 · 高速公路 · 巴士专用道 · 步行道路 · 其他道路

自动分类依据：机动车道数、中心线、中央分隔带、公交专用道、道路名称等特征；对创意工坊道路资产同样有效。

### 本次发布包含
- **道路分类管理器**：缩略图 / 名称 / 车道数列表，支持搜索、分类筛选、逐条手动分类、单条重置、全部重置
- **手动分类持久化**：保存在 xml，重启游戏后道路面板按你的设置排列
- **自定义图标**：10 个分类 + 浮动按钮图标可换成自己的 PNG（内置一套默认图标，开箱即用）
- **圆形浮动按钮**：可拖动、28–64 像素、位置自动保存、可关闭
- **UnifiedUI 集成（可选）**：把入口放进 UnifiedUI 工具栏
- **9 种语言**：跟随游戏语言或手动切换
- **两种搜索模式**：实时过滤（默认）或仅回车 / 按钮触发
- **性能**：管理器行控件池 + 可见区虚拟化，道路资产再多也不卡顿
- **热键**：Ctrl+Shift+Y 打开道路总览窗口

### 依赖与兼容
- **必须**：CitiesHarmony（Harmony 2.2+）
- **可选**：UnifiedUI（仅“加入 UnifiedUI”功能需要）
- **不兼容**：Better Road Toolbar 等同样替换道路面板父级分类的模组（二选一）
- **已验证共存**：Find It 2、Move It、TMPE、Intersection Marking Tool、Network Anarchy、Node Controller、Quay Tools、Loading Screen Mod、FPS Booster、Skyve、Lumina 等

### 安装
订阅本模组与 CitiesHarmony 后启动游戏，在「内容管理器 → 模组」确认已启用即可。进入城市后左下角出现圆形按钮。

### 已知限制
- 管理器里的手动分类需要「保存配置」并重启游戏后才会重排道路面板
- 自定义图标在启动时加载，修改后需重启游戏
- 与同类替换道路面板的模组只能二选一
