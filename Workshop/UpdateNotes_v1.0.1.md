# v1.0.1 更新说明（工坊公告）

## 精细道路分类 v1.0.1

### 修复：订阅后分类图标不显示

从创意工坊订阅本模组后，道路面板顶部 10 个分类标签的图标会变成游戏默认的小图标。

原因：旧版本只从「DLL 所在目录的 `Icons\` 文件夹」复制图标到玩家目录。
订阅安装时模组位于 `steamapps\workshop\content\255710\<id>\`，一旦该路径判断失败，
就没有任何可用的图标，只能退回游戏默认图标。

修复方式：
- 12 个默认图标**直接嵌入 DLL**，从内存读取，不再依赖任何外部文件夹
- 启动时按「玩家目录 → 内置资源 → 模组目录」顺序查找，缺哪个补哪个
- 仍会把图标写入 `%LOCALAPPDATA%\Colossal Order\Cities_Skylines\RoadCategoryMod\Icons\`，方便你替换成自己的图标
- 加载失败（例如 UI 尚未初始化）会自动重试

### 升级方式

用新版 `RoadCategoryMod.dll` 覆盖旧文件即可（**先关游戏**）。
`Icons\` 文件夹现在可以删掉——图标已经内嵌，不会影响显示。

### 已知限制（不变）
- 管理器里的手动分类需要「保存配置」并重启游戏后才会重排道路面板
- 与 Better Road Toolbar 等同样替换道路面板父级分类的模组只能二选一
